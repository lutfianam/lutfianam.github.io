Panduan Operasional Guru Piket

  1. Awal Shift Piket: Buka tab [ Pengaturan ] lalu klik "Pindai QR Konfigurasi" untuk menyelaraskan link server admin. Jika tidak ada jaringan, gunakan "Muat Data Demo" untuk pengujian offline.
  2. Proses Absensi: Kembali ke tab [ Absensi ]. Pilih kamera HP Android belakang/depan. Arahkan QR Kartu siswa ke kotak scanner.
  3. Siswa Lupa Kartu: Pilih opsi "Input Manual / Cari". Ketik NIS atau Nama Siswa, lalu tekan "Absenkan".
  4. Penguncian Double Scan: Siswa hanya bisa presensi 1x pada sesi yang sama di hari yang sama untuk mencegah duplikasi data.

Troubleshooting Kamera Android

  • Pastikan memberikan izin "Allow Camera Access" di browser Chrome/Kiwi/Edge Android.
  • Situs harus berjalan di protokol HTTPS atau localhost agar API Kamera aktif.
  • Jika kamera hitam, tekan tombol "Stop Kamera" lalu buka kembali atau ganti opsi kamera di dropdown.
