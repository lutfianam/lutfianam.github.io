Pengaturan Integrasi Cloud

Hubungkan SIPRESKA ke Google Sheets Master Data dan Google Form untuk pengiriman log presensi otomatis.

1. Master Data Google Sheets (CSV URL)

Masukkan URL Google Sheets yang telah dipublikasikan sebagai CSV (Web CSV Link). Pastikan header kolom minimal berisi: NIS, Nama, Kelas, No_WA.

2. Form Auto-Submit Google Form

SIPRESKA mengirimkan data hasil scan langsung ke Google Form di latar belakang menggunakan HTTP POST (`no-cors`).

Panduan Lengkap Operasional SIPRESKA

Petunjuk langkah demi langkah pengoperasian aplikasi untuk Guru Piket dan Tim IT Sekolah.

1

Persiapan Google Sheets & Form

  • Buat Google Sheets dengan header kolom: NIS, Nama, Kelas, No_WA.
  • Klik File > Bagikan > Publikasikan ke Web, pilih opsi format CSV lalu salin URL-nya.
  • Buat Google Form dengan pertanyaan: NIS, Nama, Kelas, Sesi, Tanggal, Waktu.
  • Buka link 'Dapatkan Link Terisi Semula' (Pre-filled Link) pada Google Form untuk mengambil Entry ID (misal entry.123456).
2

Operasional Guru Piket

  • Buka Tab [ 📷 Absensi & Scanner ] di awal piket harian.
  • Sesi presensi akan mendeteksi jam WIB secara otomatis. Sesi dapat di-override manual jika ada kegiatan khusus.
  • Arahkan Kartu QR Siswa ke kamera laptop/tablet piket.
  • Jika siswa lupa membawa kartu, ketik NIS atau Nama di kolom Input Manual NIS / Search Nama lalu tekan Enter.
3

Indikator Visual & Suara (Web Audio API)

HIJAU - Beep Tinggi Presensi Berhasil Diterima
KUNING - Beep Double Peringatan: Sudah Absen Sesi Ini
MERAH - Beep Panjang Error: NIS Tidak Ditemukan Master
4

Troubleshooting Ringkas

  • Kamera tidak terbuka: Pastikan izin browser (Camera Permission) diizinkan / `https://` atau `localhost`.
  • Internet Terputus: Aplikasi tetap mencatat presensi di simpanan lokal `localStorage`. Unduh file cadangan via tombol Ekspor Cadangan CSV di Tab Log.
  • Data siswa belum terupdate: Masuk ke Tab Pengaturan dan klik Uji & Tarik Data Master.
