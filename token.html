Hubungkan Google Sheets

Sinkronisasi topik buatanmu langsung dari spreadsheet

Cara Mempublikasikan Spreadsheet:

  1. Buka Google Sheets kamu (pastikan ada kolom: pertanyaan, kategori, mode, subtext).
  2. Klik menu File > Bagikan (Share) > Publikasikan ke web (Publish to web).
  3. Ubah format dari Web Page menjadi Comma-separated values (.csv).
  4. Klik Publikasikan lalu salin tautan/URL CSV yang dihasilkan dan tempel di bawah.

Panduan Penggunaan ToKen

Petunjuk aplikasi dan cara integrasi Google Sheets

1. Cara Penggunaan Aplikasi

  • Kocok Topik: Ketuk di mana saja pada kartu utama atau tekan tombol [Spacebar] di laptop/HP untuk mengocok pertanyaan.
  • Efek Randomizer: Saat dikocok, teks akan berganti secara acak dengan cepat sebelum menampilkan pertanyaan terpilih.
  • Pilih Filter: Sesuaikan kategori (Sekolah, Buku, Desain, Komputer, Organisasi) dan suasana obrolan (Santai 🍵, Debat 🔥, Deep Talk 💬).
  • Sukai & Tandai: Klik ikon ❤️ untuk menyimpan ke favorit, atau ikon ✅ jika pertanyaan sudah pernah dibahas.
  • Tambah Manual: Gunakan tombol [+] untuk menambahkan pertanyaan rahasia buatanmu sendiri secara instan.

2. Cara Membuat Google Sheets

Buat Google Sheet baru dan pastikan **Baris Pertama (Header)** persis berisi 4 nama kolom ini (huruf kecil semua):

pertanyaan kategori mode subtext
Apa momen mengajar paling seru minggu ini? Sekolah Santai Ceritakan kronologinya!
Gaya desain poster apa yang paling kamu suka? Desain Deep Minimalis atau vibrant?

💡 Isian kategori yang didukung: Sekolah, Buku, Desain, Komputer, Organisasi, Deep Talk.

3. Cara Menghubungkan ke ToKen

  1. Buka Google Sheets yang sudah kamu isi pertanyaan.
  2. Klik menu File > Bagikan (Share) > Publikasikan ke Web (Publish to Web).
  3. Di kotak dialog, ubah dropdown Web Page menjadi Comma-separated values (.csv).
  4. Klik tombol biru Publikasikan (Publish).
  5. Salin link URL yang diberikan oleh Google.
  6. Di ToKen, klik tombol Spreadsheet Off di kanan atas header, lalu tempel URL dan klik Simpan & Sinkronkan. Selesai! 🎉
